# jorgeeemera/tap

```sh
brew install --cask jorgeeemera/tap/locallens
```

Usa siempre el nombre completo (también en `brew upgrade --cask jorgeeemera/tap/locallens`): con el nombre corto Homebrew pide `brew trust`.

LocalLens beta no está notarizada: la primera vez, autorízala en Ajustes del Sistema › Privacidad y seguridad › Abrir igualmente. Más información: https://github.com/jorgeeemera/locallens
